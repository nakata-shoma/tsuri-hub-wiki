# ナイロンライン・フロロカーボンライン・PEライン・エステルライン

## 意味
釣り糸(ライン)の代表的な4種類の素材である。
ナイロン、フロロカーボン、PE(ポリエチレン)、エステル(ポリエステル)の違いにより、伸び・強度・感度・扱いやすさが異なる。

## 補足
- ナイロンラインは伸縮性があり扱いやすく安価で、道糸として広く使われる。
- フロロカーボンラインは伸びが少なく感度が良い上、根ズレなどの擦れに強く沈みやすいため、ハリスやリーダーとして使われることが多い。
- PEラインは同じ太さでも強度が高く、感度・飛距離に優れる一方、根ズレに弱いためリーダーを結んで使うのが一般的とされる。
- エステルラインはポリエステル素材のラインで、伸びが少なく比重が高いため水馴染みが良く、軽量なジグヘッドを使うアジングなどで感度・操作性に優れるとされる。
- エステルラインは瞬間的な負荷(ショック)に弱く切れやすい上、細い号数では擦れにも弱いため、根が荒い場所や大型魚とのやり取りには不向きとされる。
