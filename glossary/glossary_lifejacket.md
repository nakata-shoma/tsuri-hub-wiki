# ライフジャケット(救命胴衣)

## 意味
ライフジャケットとは、水に落ちた際に浮力を確保し、命を守るための安全装備である。
「救命胴衣」とも呼ばれる。
構造によって大きく「固型式」と「膨脹式」に分けられる。
固型式は発泡プラスチックなどの浮力体を内蔵したシンプルな構造で、常時着用しやすくメンテナンスも簡単とされる。
膨脹式は普段は薄くコンパクトだが、水に落ちると自動または手動でガスが注入されて膨らむ構造で、携帯性に優れる一方、作動確認や定期的な点検・メンテナンスが必要とされる(点検頻度や方法は製品ごとに異なるため、取扱説明書等で確認すること)。

## 補足
- 使われる場面・具体例:
  - 2018年2月1日から小型船舶の甲板上での着用が義務化され、2022年2月1日からは違反者への罰則が設けられているとされる(制度は改正される可能性があるため、釣行前に最新情報を国土交通省等の公式情報で確認すること)。
  - 陸からの釣りでは着用の法的義務がない場合が多いが、ボートやフローターなど水上から釣りをする場合は義務が生じるとされる。
  - 船釣りでは国土交通省認定の「桜マーク」付きライフジャケットの着用が推奨されている。
- 型式(TYPE)による分類:
  - 小型船舶用救命胴衣には、浮力・色・装備品・使用できる航行区域に応じてTYPE A・D・F・Gなどの区分があるとされる(詳細な基準は改正される可能性があるため、国土交通省の公式情報で確認すること)。
  - TYPE Aは黄色やオレンジ色など発見されやすい色に限定され、反射材や笛を備え、すべての小型船舶で使用できるとされる。
  - TYPE D・Fは使用できる航行区域が平水区域や沿岸区域などに限定され、TYPE Gは浮力補助具に近い位置づけで平水区域向けとされる。
- 小児用ライフジャケット:
  - 対象年齢はおおむね1歳以上12歳未満とされ、体重に応じて必要な浮力の目安(体重40kg以上で7.5kg以上、15~40kg未満で5kg以上、15kg未満で4kg以上など)が定められているとされる(体重区分・浮力の目安は改正される可能性があるため、購入前に最新情報を確認すること)。
  - TYPE Gには小児用の設定がないとされる。
