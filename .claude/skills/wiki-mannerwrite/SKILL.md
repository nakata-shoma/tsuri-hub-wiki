# wiki-mannerwrite

TSURI HUB wiki([CLAUDE.md](../../CLAUDE.md)参照)の`manner/`記事を、[CLAUDE.md「mannerカテゴリの執筆スタイル」](../../CLAUDE.md)および[_templates/template_manner.md](../../_templates/template_manner.md)が定める「読者に教える文章形式」で執筆・リライトするスキル。文章校正は[wiki-proofread](../wiki-proofread/SKILL.md)、出典検証は[wiki-factcheck](../wiki-factcheck/SKILL.md)の担当であり、本スキルは執筆・構成そのものを扱う。

## 対象ファイルの決定

引数: `$ARGUMENTS`

- `$ARGUMENTS` にファイルパスが指定されていれば、そのファイルを対象にする(複数可)。まだ存在しないファイルパスなら新規執筆として扱う。
- 指定がなければ、直近の会話で話題になったマナー・トピック/ファイルを対象にする。それも不明な場合はユーザーに対象トピックを確認する。
- 対象は`manner/manner_*.md`のみ(本スキルは他カテゴリの文体には適用しない)。

## 執筆スタイルの原則

1. **リード文で始める**: 最初の見出しの前に2〜4文程度の導入文を置き、なぜこのマナーを知っておく必要があるかを語りかける。「概要」「内容」のような無機質な定型見出しの直後にいきなり箇条書きを並べない。
2. **見出しはトピックに合わせて言い換える**: `template_manner.md`の見出し例(具体的に何をすればよいか/なぜ必要か/守られない場合どうなるか)はあくまで型である。実際の見出しは、そのトピックの内容に即した具体的な言葉にする(例:「『黙認』は権利ではない」「拡散の先に起きること」)。
3. **本文は文章で語る**: 箇条書きは、法律の一覧など本当に列挙が必要な場面に限定する。それ以外は、だ・である調・1文1行のつながった文章で説明する。CLAUDE.mdの執筆ルール(常体・一文一義・ひらがな開き)はそのまま適用する。
4. **断定を避ける**: 罰則の有無・強制力、地域差のある慣習など断定できない事項には「要確認」マーカーを付ける、またはblockquoteで留保を明記する。情報源によって記述が食い違う場合は、どちらかに寄せず両論を併記する。
5. **「守られない場合の影響」には断定回避のblockquoteを必ず入れる**: 罰則の有無や強制力は水域・施設ごとに異なるため断定しないという趣旨のblockquoteを、当該セクションの直前に置く(CLAUDE.md「情報収集時の注意事項」)。法律に踏み込む場合は[manner_law.md](../../manner/manner_law.md)への導線も検討する。
6. **関連記事は文脈の中でリンクする**: 関連する他のmanner記事・glossary記事があれば、末尾に機械的なリンク集を作るのではなく、文脈に応じて本文中に`[manner_xxx.md](manner_xxx.md)`や`[glossary_xxx.md](../glossary/glossary_xxx.md)`を挿入する。
7. **構造的な一貫性は崩さない**: frontmatter(status/category/last_updated)、「用語集連携」「出典」セクションは他カテゴリと同じ構造を維持する。文体・見出しの言い回しだけを変え、サイト全体の相互参照や自動処理を壊さない。関連用語がない場合は「(該当なし)」の記載を残す(safetyカテゴリの「関連用語」空欄化とは扱いが異なる点に注意)。

## 新規執筆の場合

- WebSearch等で一次情報(公益財団法人日本釣振興会、水産庁、都道府県・市町村の公式ページなど)を優先して収集してから執筆する。CLAUDE.md「情報収集時の注意事項」により、マナー・ルールの記述は出典と確認日を必須とする。
- 出典を集め終えてから、上記スタイル原則に沿って本文を書く。
- 法令・罰則に踏み込む内容は、都道府県・水域ごとに異なり断定できない旨を必ず明記する。
- 執筆後、`INDEX.md`「3. manner」の表に行を追加する。

## 既存記事のリライトの場合

- 事実・出典・「要確認」マーカー・断定回避のblockquoteの内容は変更せず、構成と文体のみを見直す(新しい事実を調べ直すことはしない)。
- frontmatterの`last_updated`を実行日に更新する。
- `INDEX.md`の該当行の更新日もあわせて更新する(ステータスに変更がなければステータス自体は変更しない)。

## 出力形式

- ファイルへの反映(Write/Edit)を直接行う。校正スキルと異なり、レポートのみに留めない。
- 変更後、対象ファイルごとに以下を簡潔に報告する。

```
## manner記事の執筆・リライト結果: <ファイル名>

- 種別: 新規執筆 / 既存リライト
- 主な変更点: (構成変更/文体変更/事実変更なしなど)
- 出典: (新規収集した出典があれば列挙。リライトのみの場合は「変更なし」)
```

## 注意事項
- 本スキルはmannerカテゴリ専用である。他カテゴリ(species/category/technique/safety等)の文体を無断で変更しない。
- 見出しの言い回しを自由に変えてよいのはmannerカテゴリの特例であり、`_templates/`配下のテンプレート自体を書き換える場合はユーザーに確認する。
- [manner_law.md](../../manner/manner_law.md)は法律を列挙する性質上、箇条書きが本文の主要部分を占める。無理に文章化して列挙性を損なわないこと。
