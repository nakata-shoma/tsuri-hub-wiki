# wiki-relatedterms

TSURI HUB wiki([CLAUDE.md](../../CLAUDE.md)参照)の`glossary/`記事について、「関連用語」セクションの網羅性とリンクの相互性を整備するスキル。文章校正は[wiki-proofread](../wiki-proofread/SKILL.md)、出典検証は[wiki-factcheck](../wiki-factcheck/SKILL.md)の担当であり、本スキルは扱わない。

方針:
1. 対象ファイルに関連する用語で、既にglossary記事があるものは相互リンクする(対象ファイル→既存記事、既存記事→対象ファイルの両方向)。
2. 記事がまだ存在しない用語は、`_templates/template_glossary.md`に基づく新規スタブ記事を作成し、リンクする。

## 対象ファイルの決定

引数: `$ARGUMENTS`

- `$ARGUMENTS` にファイルパスが指定されていれば、そのファイルを対象にする(複数可)。新規追加・編集した記事を指定するのが基本的な使い方。
- 指定がなければ、直近で作成・編集したglossaryファイルを対象にする。それも不明な場合はユーザーに対象ファイルを確認する。
- 対象は`glossary/glossary_*.md`のみ(「関連用語」セクションはglossary固有のテンプレート項目のため)。

## 処理フロー

### 1. 候補語の抽出
- 対象ファイルの「意味」「補足」本文、および既存の「関連用語」セクション(プレースホルダーのテキスト、例: 「今後、ウキ下・タナ取りなど関連語を追加予定」も含む)から、釣り専門用語らしき語を候補として抽出する。
- 対象ファイル自身がテーマとする語(タイトルの用語そのもの)は候補から除く。

### 2. 既存記事の有無を確認
候補語ごとに、`glossary/`配下に該当記事が既にあるか確認する。
- ファイル名の見当がつく場合はGlobで直接確認する。
- 確実でない場合は、`glossary/*.md`の見出し(`# 用語名(読み仮名)`)をGrepし、表記ゆれ・別名・地方名で同一の語を指していないか照合する(例:「サルカン」と「スイベル」のような同義語)。
- 既存記事が見つかった候補 → 「既存記事へのリンク」として扱う。
- 見つからない候補 → 「新規作成候補」として扱う。ただし本当に独立した用語として記事を割く価値があるか(対象ファイルの本文だけで説明が完結する些末な語ではないか)を判断し、疑わしい場合は候補から外してよい。

### 3. 既存記事への相互リンク
- 対象ファイルの「関連用語」セクションに `[glossary_xxx.md](glossary_xxx.md)(用語名)` 形式でリンクを追加する(既に同じリンクがあれば追加しない)。プレースホルダーのテキストのみだった場合は置き換える。
- 相互性の担保: リンク先の既存記事側の「関連用語」セクションを確認し、対象ファイルへのリンクがなければそちらにも追加する(双方向リンク)。

### 4. 新規スタブ記事の作成
新規作成候補について:
- `_templates/template_glossary.md`の構成に沿って `glossary/glossary_<slug>.md` を作成する。`<slug>`は既存ファイル名の命名傾向(ローマ字表記)に合わせる。
- frontmatterは `status: 調査中` / `category: glossary` / `last_updated: <実行日>` とする。
- 見出しは `# 用語名(読み仮名)` とする。
- 「意味」「補足」「出典」は空欄のまま残す(未調査の内容を創作しない。CLAUDE.mdの「未確認・推測を含む内容は本文と明確に区別する」方針に従い、本文執筆は別途の調査作業とする)。
- 「関連用語」に対象ファイルへのリンクを入れておく。
- 対象ファイル側の「関連用語」にも、新規作成したファイルへのリンクを追加する。
- `INDEX.md`の「8. glossary(用語集)」表に行を追加する(INDEX.md「14. 運用メモ」の指示どおり、ファイル名・トピック・ステータス・更新日を記載)。

### 5. 再帰の抑制
新規作成したスタブ記事自体の「関連用語」候補をさらに追いかけて連鎖的に記事を増やすことはしない(1回の実行につき、対象ファイルから見た1階層のみを処理する)。スタブ記事の中身を書く際に、改めて本スキルを実行する運用とする。

## 出力形式

以下の形式で日本語のレポートとして出力する。

```
## 関連用語の見直し結果: <ファイル名>

### 追加したリンク(既存記事との相互リンク)
- <対象ファイル> → <既存記事>(用語名)
- <既存記事> → <対象ファイル>(逆方向、必要だった場合)

### 新規作成したスタブ記事
- glossary/glossary_<slug>.md(用語名) — INDEX.mdにも追加済み。本文は未執筆(調査中)

### 候補から除外した語
- <語>: 除外理由

### 変更なし
- 該当があれば列挙(既に相互リンク済みだった語など)
```

## 注意事項
- 本スキルはファイルの新規作成・既存ファイルへのリンク追加を直接実行する(校正・出典検証スキルと異なり、レポートのみに留めない)。ただし新規スタブ記事の本文執筆・事実の追記は行わない。
- 新規作成候補が多数(目安5件超)になった場合は、作成前に候補一覧をユーザーに提示し、続行してよいか確認する。
