# wiki-safetywrite

TSURI HUB wiki([CLAUDE.md](../../CLAUDE.md)参照)の`safety/`記事を、[CLAUDE.md「safetyカテゴリの執筆スタイル」](../../CLAUDE.md)および[_templates/template_safety.md](../../_templates/template_safety.md)が定める「読者に教える文章形式」で執筆・リライトするスキル。文章校正は[wiki-proofread](../wiki-proofread/SKILL.md)、出典検証は[wiki-factcheck](../wiki-factcheck/SKILL.md)の担当であり、本スキルは執筆・構成そのものを扱う。

## 対象ファイルの決定

引数: `$ARGUMENTS`

- `$ARGUMENTS` にファイルパスが指定されていれば、そのファイルを対象にする(複数可)。まだ存在しないファイルパスなら新規執筆として扱う。
- 指定がなければ、直近の会話で話題になった安全トピック・ファイルを対象にする。それも不明な場合はユーザーに対象トピックを確認する。
- 対象は`safety/safety_*.md`のみ(本スキルは他カテゴリの文体には適用しない)。

## 執筆スタイルの原則

1. **リード文で始める**: 最初の見出しの前に2〜4文程度の導入文を置き、なぜこのテーマを知っておく必要があるかを語りかける。「概要」「被害内容」のような無機質な定型見出しの直後にいきなり箇条書きを並べない。
2. **見出しはトピックに合わせて言い換える**: `template_safety.md`の見出し例(どんな危険があるか/どう備えるか/もしものとき)はあくまで型である。実際の見出しは、そのトピックの内容に即した具体的な言葉にする(例:「震えが止まったら要注意」「乗らないに勝る対策はない」)。
3. **本文は文章で語る**: 箇条書きは、手順・選択肢の使い分け・他記事への導線など、本当に列挙が必要な場面に限定する。それ以外は、だ・である調・1文1行のつながった文章で説明する。CLAUDE.mdの執筆ルール(常体・一文一義・ひらがな開き)はそのまま適用する。
4. **断定を避ける**: 症状の個人差、罰則・制度の変更可能性、統計の出典差など断定できない事項には「要確認」マーカーを付ける。情報源によって記述が食い違う場合は、どちらかに寄せず両論を併記する。
5. **応急処置には受診の一文を必ず入れる**: 応急処置に類するセクションには、症状が強い・意識障害を伴う等の場合は医療機関の受診や救急要請を促す一文をblockquoteで入れる(CLAUDE.md「情報収集時の注意事項」)。
6. **関連記事は文脈の中でリンクする**: 関連する他のsafety記事があれば、末尾に機械的なリンク集を作るのではなく、文脈に応じて本文中に`[safety_xxx.md](safety_xxx.md)`を挿入する。
7. **構造的な一貫性は崩さない**: frontmatter(status/category/last_updated)、「関連用語」「出典」セクションは他カテゴリと同じ構造を維持する。文体・見出しの言い回しだけを変え、サイト全体の相互参照や自動処理を壊さない。「関連用語」に該当する語がない場合は空欄のままでよい。

## 新規執筆の場合

- WebSearch等で一次情報(海上保安庁ウォーターセーフティガイド、水産庁、環境省、日本釣振興会「安全対策13ヶ条」など)を優先して収集してから執筆する。CLAUDE.md「情報収集時の注意事項」により、安全・危険生物の情報は出典と確認日を必須とする。
- 出典を集め終えてから、上記スタイル原則に沿って本文を書く。
- ステータスは内容の完成度に応じて設定するが、安全に関わる内容は出典検証前提として「要出典確認」を基本とする。
- 執筆後、`INDEX.md`「4. safety」の表に行を追加する。

## 既存記事のリライトの場合

- 事実・出典・「要確認」マーカーの内容は変更せず、構成と文体のみを見直す(新しい事実を調べ直すことはしない)。
- frontmatterの`last_updated`を実行日に更新する。
- `INDEX.md`の該当行の更新日もあわせて更新する。

## 出力形式

- ファイルへの反映(Write/Edit)を直接行う。校正スキルと異なり、レポートのみに留めない。
- 変更後、対象ファイルごとに以下を簡潔に報告する。

```
## safety記事の執筆・リライト結果: <ファイル名>

- 種別: 新規執筆 / 既存リライト
- 主な変更点: (構成変更/文体変更/事実変更なしなど)
- 出典: (新規収集した出典があれば列挙。リライトのみの場合は「変更なし」)
```

## 注意事項
- 本スキルはsafetyカテゴリ専用である。他カテゴリ(species/category/technique/manner等)の文体を無断で変更しない。
- 見出しの言い回しを自由に変えてよいのはsafetyカテゴリの特例であり、`_templates/`配下のテンプレート自体を書き換える場合はユーザーに確認する。
